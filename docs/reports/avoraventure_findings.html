CRITICAL
The bare domain serves a blank page to crawlers and link-preview bots
src/app/page.tsx — the root route is a client-only component: 'use client', does nothing but router.replace() inside a useEffect, returns null. There is no server-rendered content and no page-specific metadata at avoraventure.com/. Anything that reads HTML without running JS — Google's initial crawl pass, Slack/LinkedIn/Twitter link-unfurl bots, a curl request — gets an empty body.
Fix: Make root either a real server component with proper content + metadata, or a server-side redirect (redirect() in a server component, or a Next.js next.config.ts rewrite) instead of a client-side one. Crawlers need something in the initial HTML response.
CRITICAL
Every cold link forces a click-through before any content loads
Root → redirects to /intro (a full-screen WebGL shader splash: logo, "Institutional AI Infrastructure," one button) → user must click "Explore Services" → then lands on /home, which has the real page. This is gated per-session via sessionStorage, so every new tab, incognito visit, or freshly clicked link from an ad, cold email, or LinkedIn post hits the splash first. For a first-time cold visitor — the exact audience paid acquisition exists to reach — that's an extra click and a few seconds of shader animation between them and any actual information.
Fix: Keep the splash for direct brand-visit traffic if you like the moment, but bypass it for traffic arriving with UTM params, from paid campaigns, or via direct deep-links to /home, /work, /blog. Cold traffic should never pay an extra click for a first impression it didn't ask for.
